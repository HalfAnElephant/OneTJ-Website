## ViewModel 概述

在 OneTJ 的分层 MVVM 架构中，ViewModel 是展示层状态持有者，连接 View 与 Application Service。ViewModel **不得直接调用 API，不得直接访问缓存 Repository**，页面用例编排交由 Application Service 完成。

## BaseViewModel

所有 ViewModel 应继承 `BaseViewModel<TEvent>`，位于 `lib/app/presentation/base_view_model.dart`：

```dart
class BaseViewModel<TEvent> extends ChangeNotifier {
  String? errorMessage;
  String? errorCode;
  bool loading = false;
  bool _isDisposed = false;

  final StreamController<TEvent> _eventController =
      StreamController<TEvent>.broadcast();

  bool get isDisposed => _isDisposed;
  Stream<TEvent> get events => _eventController.stream;

  @protected
  void emit(TEvent event) {
    if (_isDisposed || _eventController.isClosed) return;
    _eventController.add(event);
  }

  @override
  void notifyListeners() {
    if (_isDisposed) return;
    super.notifyListeners();
  }

  @override
  void dispose() {
    _isDisposed = true;
    _eventController.close();
    super.dispose();
  }
}
```

要点：

- `BaseViewModel` 本质是 `ChangeNotifier`，状态变更后调用 `notifyListeners()` 通知 View
- `events` 是 `Stream<TEvent>`，用于发送一次性 UI 事件（导航、SnackBar、Toast、更新提示）
- `emit()` 为受保护方法，供子类发送事件
- 释放后（`isDisposed`）的 `notifyListeners` 与 `emit` 会被安全忽略

## UiEvent

`lib/app/presentation/ui_event.dart` 定义了事件类型：

```dart
class UiEvent extends BaseEvent {
  final String? message;
  final String? code;
  const UiEvent({this.message, this.code});
}

class ShowToastEvent extends UiEvent { ... }
class ShowSnackBarEvent extends UiEvent { ... }
class NavigateEvent extends UiEvent {
  final String route;
  const NavigateEvent(this.route);
}
class AppUpdateAvailableEvent extends UiEvent { ... }
class AppUpdateFailedEvent extends UiEvent { ... }
```

## ViewModel 结构

### 基本结构

```dart
class DashboardViewModel extends BaseViewModel<UiEvent> {
  DashboardViewModel({DashboardDataService? dataService})
      : _dataService = dataService ?? DashboardDataService();

  final DashboardDataService _dataService;

  // 状态（私有，通过 getter 暴露）
  SchoolCalendarData? _calendar;
  bool _calendarLoading = true;

  // 状态 getter
  SchoolCalendarData? get calendar => _calendar;
  bool get calendarLoading => _calendarLoading;

  // 业务方法：调用 Application Service，更新状态，通知 View
  Future<void> loadSchoolCalendar() async {
    try {
      final data = await _dataService.getSchoolCalendar();
      _calendar = data;
    } catch (error) {
      emit(ShowSnackBarEvent(message: 'Failed to load school calendar'));
    } finally {
      _calendarLoading = false;
      notifyListeners();
    }
  }
}
```

### 依赖注入约定

- 通过构造器注入依赖，默认值从 `appLocator` 获取或直接 `new`
- 新 Application Service 必须通过构造器注入
- 不要在 ViewModel 中新增 service locator 查询

```dart
DashboardViewModel({
  DashboardDataService? dataService,
  SettingsRepository? settingsRepository,
})  : _dataService = dataService ?? DashboardDataService(),
      _settingsRepository =
          settingsRepository ?? appLocator<SettingsRepository>();
```

## 事件发送

### 导航事件

```dart
emit(NavigateEvent(RoutePaths.home));
```

### 提示事件

```dart
emit(ShowSnackBarEvent(message: '加载失败'));
emit(ShowToastEvent(message: '已复制'));
```

### 应用更新事件

```dart
emit(AppUpdateAvailableEvent(updateInfo: info));
emit(AppUpdateFailedEvent(error: error, stackTrace: stackTrace));
```

## 错误处理

### Try-Catch 模式

```dart
Future<void> loadStudentInfo() async {
  try {
    final StudentInfoData data = await _dataService.getStudentInfo();
    _departmentName = data.deptName;
  } catch (error) {
    emit(ShowSnackBarEvent(message: 'Failed to load student info: $error'));
  } finally {
    _studentLoading = false;
    notifyListeners();
  }
}
```

### 错误状态

`BaseViewModel` 提供 `errorMessage` / `errorCode` / `loading` 通用字段，可按需使用。

## 数据转换

### 通过 Application Service 获取并转换数据

```dart
Future<void> loadCourseSchedule() async {
  try {
    final CourseScheduleData data = await _dataService.getCourseSchedule();
    final TimetableIndex index =
        const TimetableIndexBuilder().buildIndex(data);
    final entries = List<TimetableEntry>.from(index.allEntries)
      ..sort((a, b) {
        if (a.dayOfWeek != b.dayOfWeek) {
          return a.dayOfWeek.compareTo(b.dayOfWeek);
        }
        if (a.timeStart != b.timeStart) {
          return a.timeStart.compareTo(b.timeStart);
        }
        return a.timeEnd.compareTo(b.timeEnd);
      });
    _timetableEntries = entries;
    _timetableIndex = index;
  } catch (error) {
    _timetableIndex = null;
    emit(ShowSnackBarEvent(message: 'Failed to load timetable: $error'));
  } finally {
    _timetableLoading = false;
    notifyListeners();
  }
}
```

## 生命周期

### dispose

子类覆写 `dispose` 时需取消订阅与计时器，并调用 `super.dispose()`：

```dart
@override
void dispose() {
  _upcomingRefreshTimer?.cancel();
  _settingsSub?.cancel();
  super.dispose();
}
```

## 最佳实践

### 1. 单一职责

每个 ViewModel 只负责一个视图的逻辑。

### 2. 不直接操作 UI

ViewModel 不应持有 `BuildContext` 或直接操作 UI 组件，通过 `emit(UiEvent)` 通知 View 处理：

```dart
// ❌ 不好
void showError(BuildContext context) {
  ScaffoldMessenger.of(context).showSnackBar(...);
}

// ✅ 好
void sendErrorEvent() {
  emit(ShowSnackBarEvent(message: '...'));
}
```

### 3. 不直接调用 API / Repository

数据获取与缓存编排交给 Application Service：

```dart
// ❌ 不好（ViewModel 直接碰 repository 与 API）
Future<void> load() async {
  final repo = SchoolCalendarRepository();
  await repo.warmUp();
  final data = await TongjiApi().fetchSchoolCalendarCurrentTerm();
}

// ✅ 好
Future<void> load() async {
  final data = await _dataService.getSchoolCalendar();
}
```

### 4. 及时释放资源

```dart
@override
void dispose() {
  _subscription?.cancel();
  _timer?.cancel();
  super.dispose();
}
```

## 示例：完整的 ViewModel

```dart
class CetScoreViewModel extends BaseViewModel<UiEvent> {
  CetScoreViewModel({CetScoreDataService? dataSource})
      : _dataSource = dataSource ?? CetScoreDataService();

  final CetScoreDataService _dataSource;

  CetScoreData? _data;
  bool _loading = true;

  CetScoreData? get data => _data;
  bool get loading => _loading;

  Future<void> load() async {
    _loading = true;
    notifyListeners();
    try {
      _data = await _dataSource.getCetScores();
    } catch (error) {
      emit(ShowSnackBarEvent(message: 'Failed to load CET scores: $error'));
    } finally {
      _loading = false;
      notifyListeners();
    }
  }
}
```
