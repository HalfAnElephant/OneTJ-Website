## 开发环境要求

### 必需工具

| 工具 | 版本要求 | 说明 |
|------|---------|------|
| **Flutter SDK** | `ohos_flutter_3.35.7` | 通过 FVM 固定版本（见 `.fvmrc`） |
| **Dart SDK** | `^3.6.2` | 随 Flutter 安装 |
| **Git** | 2.0+ | 版本控制 |
| **IDE** | - | VS Code 或 Android Studio |

### 可选工具

| 工具 | 说明 |
|------|------|
| **FVM** | Flutter 版本管理工具 |
| **鸿蒙 Command Line Tools** | 编译鸿蒙版本 |

## FVM 安装

### 为什么使用 FVM

- 管理多个 Flutter 版本
- 确保团队成员使用相同版本（`.fvmrc` 固定）
- 方便切换不同项目的 Flutter 版本

### 安装 FVM

::: code-group

```sh [macOS]
brew tap leoafarias/fvm
brew install fvm

# 或通过 pub
dart pub global activate fvm
```

```sh [Linux]
dart pub global activate fvm

# 或通过 snap
snap install fvm
```

```sh [Windows]
choco install fvm

# 或通过 pub
dart pub global activate fvm
```

:::

### FVM 常用命令

```bash
# 安装 Flutter 版本
fvm install <version>

# 列出已安装版本
fvm list

# 设置项目使用的版本
fvm use <version>

# 使用指定版本运行命令
fvm flutter run

# 查看项目固定版本
fvm flutter --version
```

## Flutter 安装

### 鸿蒙版 Flutter

OneTJ 使用支持鸿蒙的 Flutter 版本，版本名固定为 `ohos_flutter_3.35.7`：

```bash
# 克隆鸿蒙版 Flutter
git clone -b oh-3.35.7-release https://gitcode.com/CPF-Flutter/flutter_flutter.git
```

将克隆的 SDK 放入 FVM 版本目录，并命名为 `ohos_flutter_3.35.7`：

```
# macOS: ~/.fvm/versions/
# Windows: %USERPROFILE%\fvm\versions\
```

项目通过 `.fvmrc` 固定使用该 SDK：

```json
{
  "flutter": "ohos_flutter_3.35.7"
}
```

使用 `fvm flutter --version` 确认版本后再继续。

## SDK 本地补丁

当前 OpenHarmony Flutter SDK 需要两个本地补丁（重新安装或升级 SDK 后需重新应用）。

### Windows：Visual Studio 2026（18.x）兼容补丁

SDK 工具只显式识别 Visual Studio 2022（17.x），检测到 VS 2026（18.x）时会错误回退到 CMake 生成器 `Visual Studio 16 2019`。

- 文件：`<FVM SDK>/packages/flutter_tools/lib/src/windows/visual_studio.dart`
- 在 `cmakeGenerator` 的 `switch (_majorVersion)` 中添加：

  ```dart
  18 => 'Visual Studio 18 2026',
  ```

- 修改后删除可再生的工具快照使其重建：

  ```powershell
  Remove-Item <FVM SDK>\bin\cache\flutter_tools.snapshot
  Remove-Item <FVM SDK>\bin\cache\flutter_tools.stamp
  fvm flutter --version
  ```

- 最后删除旧 Windows CMake 缓存并重新构建：

  ```powershell
  Remove-Item build\windows\x64 -Recurse -Force
  fvm flutter build windows --debug
  ```

### OpenHarmony Flutter 的 `meta` 1.17 兼容补丁

`full_svg_flutter 1.3.1` 依赖 `meta ^1.17.0`，但 SDK 的 framework 与 `flutter_test` 仍固定为 `1.16.0`。需将以下两处改为 `meta: 1.17.0`：

- `<FVM SDK>/packages/flutter/pubspec.yaml`
- `<FVM SDK>/packages/flutter_test/pubspec.yaml`

## 鸿蒙开发工具（可选）

如需编译鸿蒙版本，需安装鸿蒙 [Command Line Tools](https://developer.huawei.com/consumer/cn/download/command-line-tools-for-hmos)，并将解压路径下的 `command-line-tools\bin` 配置到系统 PATH。

## IDE 配置

### VS Code

1. 安装 VS Code
2. 安装扩展：
   - **Flutter** (Flutter 官方扩展)
   - **Dart** (Dart 语言支持)

#### 配置 FVM 路径

创建 `.vscode/settings.json`：

```json
{
  "dart.flutterSdkPath": ".fvm/flutter_sdk",
  "search.exclude": {
    "**/.fvm": true
  },
  "files.watcherExclude": {
    "**/.fvm": true
  },
  "dart.lineLength": 100
}
```

### Android Studio

1. 安装 Android Studio
2. 安装 Flutter 和 Dart 插件
3. 配置 Flutter SDK 路径：
   - Settings → Languages & Frameworks → Flutter
   - Flutter SDK path: 设置为 FVM 的 Flutter 路径

## 环境验证

### Flutter Doctor

```bash
fvm flutter doctor
```

确认 Flutter 版本、Android toolchain、IDE 插件等是否正确安装。

## 代码质量检查

项目提供专门的静态分析脚本，**不要使用裸 `fvm flutter analyze` 作为应用代码质量的绿灯依据**（该脚本只分析 `lib` 与 `test`，排除 `local_packages` vendor fork）：

```powershell
# Windows（PowerShell）
.\scripts\flutter_analyze_app.ps1

# Linux / macOS（Bash）
./scripts/flutter_analyze_app.sh
```

默认 analyzer error 会使检查失败，warning 与 info 会输出但暂不阻断；需要严格检查时：

```powershell
.\scripts\flutter_analyze_app.ps1 -Strict
```

```bash
./scripts/flutter_analyze_app.sh --strict
```

## 常见问题

### FVM 命令找不到

```bash
# 确认 FVM 已安装
which fvm

# 或添加到 PATH
# macOS/Linux: ~/.pub-cache/bin 或 ~/.local/bin
# Windows: %LOCALAPPDATA%\Pub\Cache\bin
```

### Flutter 版本不匹配

```bash
# 检查项目固定版本
Get-Content .fvmrc

# 安装对应版本
fvm install <version>
fvm use <version>
```

### 依赖安装失败

```bash
# 清除缓存
fvm flutter pub cache repair

# 重新安装
fvm flutter pub get
```

### 鸿蒙构建问题

鸿蒙开发环境配置较为复杂，构建中遇到问题请及时联系项目维护者。
