## 主题概述

OneTJ 使用 Material Design 3 主题系统，主题由 **ThemeRepository（持久化偏好）+ ThemeColorSchemeBuilder（生成配色）+ ThemeChangeNotifier（对外通知）** 三部分协作完成，用户可在设置页动态修改主题色与主题模式。

## 主题架构

```
ThemeRepository (Hive 持久化 ThemePreferences)
        │ addListener
        ↓
ThemeChangeNotifier (ChangeNotifier)
        │ buildLight / buildDark
        ↓
ThemeColorSchemeBuilder → ColorScheme.fromSeed
        │
        ↓
MaterialApp (ListenableBuilder 监听)
```

## 核心类

### ThemeChangeNotifier

`lib/app/theme/theme_change_notifier.dart`，对外暴露亮色 / 暗色 `ColorScheme` 与 `ThemeMode`：

```dart
class ThemeChangeNotifier extends ChangeNotifier {
  ThemeChangeNotifier({ThemeRepository? repository})
      : _repository = repository ?? appLocator<ThemeRepository>() {
    _repository.addListener(_onPreferencesChanged);
    final prefs = _repository.preferences;
    _lightColorScheme = ThemeColorSchemeBuilder.buildLight(prefs);
    _darkColorScheme = ThemeColorSchemeBuilder.buildDark(prefs);
  }

  ColorScheme get lightColorScheme => _lightColorScheme;
  ColorScheme get darkColorScheme => _darkColorScheme;
  ThemeMode get themeMode => _repository.preferences.themeMode;

  Future<void> setThemeMode(ThemeMode mode) =>
      _repository.setThemeMode(mode);
  Future<void> setLightSeedColor(Color color) =>
      _repository.setLightSeedColor(color);
  // ...
}
```

### ThemeColorSchemeBuilder

`lib/app/theme/theme_color_scheme_builder.dart`，纯函数构建 `ColorScheme`：

```dart
static ColorScheme build({
  required ThemePreferences preferences,
  required Brightness brightness,
}) {
  final isLight = brightness == Brightness.light;
  final seedColor =
      isLight ? preferences.lightSeedColor : preferences.darkSeedColor;
  final secondaryColor =
      isLight ? preferences.lightSecondaryColor : preferences.darkSecondaryColor;

  return ColorScheme.fromSeed(
    seedColor: seedColor,
    secondary: secondaryColor,
    brightness: brightness,
  );
}
```

主色作为 seed 生成全套配色，辅色通过 `ColorScheme.fromSeed` 的 `secondary` 参数和谐化到主色的色相体系。

## 在 MaterialApp 中使用

`lib/main.dart` 通过 `ListenableBuilder` 监听主题变化：

```dart
final ThemeChangeNotifier themeNotifier = appLocator<ThemeChangeNotifier>();
return ListenableBuilder(
  listenable: themeNotifier,
  builder: (context, child) {
    return MaterialApp.router(
      theme: ThemeData(
        colorScheme: themeNotifier.lightColorScheme,
        useMaterial3: true,
      ),
      darkTheme: ThemeData(
        colorScheme: themeNotifier.darkColorScheme,
        useMaterial3: true,
      ),
      themeMode: themeNotifier.themeMode,
      routerConfig: AppRouter.router,
    );
  },
);
```

## ThemePreferences

主题偏好存储于 `lib/models/theme_preferences.dart`，由 `ThemeRepository` 持久化到 Hive：

- `themeMode`：`ThemeMode.system` / `light` / `dark`
- `lightSeedColor` / `lightSecondaryColor`：亮色主色 / 辅色
- `darkSeedColor` / `darkSecondaryColor`：暗色主色 / 辅色
- `homeLayout`：主页布局（功能宫格等）

### 主题模式选项

| 模式 | 说明 |
|------|------|
| `ThemeMode.system` | 跟随系统设置 |
| `ThemeMode.light` | 始终使用亮色主题 |
| `ThemeMode.dark` | 始终使用暗色主题 |

## 在设置页修改主题

用户可在设置页调整主题（`lib/features/settings/`），包括：

- 切换亮色 / 暗色 / 跟随系统
- 通过 `flutter_colorpicker` 自定义亮色 / 暗色主色与辅色
- 重置为默认主题

```dart
// 示例：设置主题模式
await themeNotifier.setThemeMode(ThemeMode.dark);

// 示例：设置亮色主色
await themeNotifier.setLightSeedColor(const Color(0xFF6750A4));
```

## ColorScheme 使用

### 获取主题颜色

```dart
// 获取主色调
Theme.of(context).colorScheme.primary

// 获取背景色
Theme.of(context).colorScheme.surface

// 获取错误色
Theme.of(context).colorScheme.error
```

### 使用主题颜色构建组件

```dart
Container(
  color: Theme.of(context).colorScheme.primaryContainer,
  child: Text(
    '文本',
    style: TextStyle(
      color: Theme.of(context).colorScheme.onPrimaryContainer,
    ),
  ),
)
```

## 自定义组件主题

在 `MaterialApp` 的 `theme` / `darkTheme` 中可按需扩展组件主题：

```dart
theme: ThemeData(
  colorScheme: themeNotifier.lightColorScheme,
  useMaterial3: true,
  elevatedButtonTheme: ElevatedButtonThemeData(
    style: ElevatedButton.styleFrom(
      padding: const EdgeInsets.symmetric(horizontal: 24, vertical: 12),
      shape: RoundedRectangleBorder(
        borderRadius: BorderRadius.circular(8),
      ),
    ),
  ),
),
```
