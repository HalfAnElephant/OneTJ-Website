## pubspec.yaml 概述

`pubspec.yaml` 是 Flutter 项目的核心配置文件，定义了项目的基本信息、依赖项和资源文件。

## 项目基本信息

```yaml
name: onetj
description: "A new Flutter project."
publish_to: 'none'
version: 2.5.0+18
```

| 字段 | 说明 |
|------|------|
| `name` | 项目名称，必须唯一且小写 |
| `description` | 项目描述 |
| `publish_to` | 发布目标，`none` 表示不发布到 pub.dev |
| `version` | 版本号，格式为 `version+buildNumber`（当前 `2.5.0+18`） |

## 环境配置

```yaml
environment:
  sdk: ^3.6.2
```

指定项目所需的 Dart SDK 版本。

## 核心依赖

```yaml
dependencies:
  flutter:
    sdk: flutter
  flutter_localizations:
    sdk: flutter
  intl: any
  hive: ^2.2.3
  path: ^1.9.0
  path_provider: ^2.1.5
  cupertino_icons: ^1.0.8
  flutter_launcher_icons: ^0.13.1
  flutter_colorpicker: ^1.1.0
  go_router: ^14.2.0
  uuid: ^4.4.2
  shared_preferences: ^2.3.2
  flutter_inappwebview:
    path: ./local_packages/flutter_inappwebview/flutter_inappwebview
  http: ^1.6.0
  crypto: ^3.0.6
  json_annotation: ^4.9.0
  logging: ^1.3.0
  get_it: ^8.0.3
  device_info_plus: ^10.1.2
```

### 依赖说明

| 依赖 | 用途 |
|------|------|
| **flutter / flutter_localizations** | Flutter 框架核心与国际化支持 |
| **intl** | 国际化和本地化工具 |
| **hive** | 轻量级本地数据库（配合 `path_provider` 定位存储路径） |
| **path / path_provider** | 路径处理与平台目录定位 |
| **go_router** | 声明式路由管理 |
| **http** | HTTP 请求库 |
| **crypto** | 摘要与加密工具 |
| **json_annotation** | JSON 序列化注解 |
| **logging** | 日志记录 |
| **get_it** | 依赖注入容器 |
| **uuid** | 生成 UUID（OAuth `state`） |
| **shared_preferences** | 键值对存储 |
| **flutter_launcher_icons** | 生成应用图标 |
| **flutter_colorpicker** | 主题颜色选择器 |
| **flutter_inappwebview** | 应用内 WebView（本地 OpenHarmony fork） |
| **device_info_plus** | 设备信息（鸿蒙分支覆盖） |

## Flutter 配置

```yaml
flutter:
  uses-material-design: true
  assets:
    - assets/icon/logo.jpg
    - assets/media/
    - assets/pictures/1.jpg
    - assets/icons/fluentemoji/
    - assets/icons/function_grid/
    - assets/icons/function_grid/input_latin_letters_3d.png
    - assets/icons/function_grid/spiral_calendar_3d.png
  generate: true
```

### 配置项说明

| 配置项 | 说明 |
|--------|------|
| `uses-material-design` | 启用 Material Design |
| `assets` | 静态资源文件列表 |
| `generate` | 启用国际化代码生成（配合根目录 `l10n.yaml`） |

## 应用图标配置

```yaml
flutter_launcher_icons:
  android: "launcher_icon"
  ios: false
  image_path: "assets/icon/logo.jpg"
```

使用 `flutter_launcher_icons` 插件自动生成 Android 应用图标。

## 添加新依赖

### 添加 pub.dev 依赖

```bash
fvm flutter pub add <package-name>
```

### 添加本地依赖

```yaml
dependencies:
  my_package:
    path: ./path/to/package
```

### 添加 Git 依赖

```yaml
dependencies:
  my_package:
    git:
      url: https://github.com/username/repo.git
      ref: main
```

## 常用命令

```bash
# 获取依赖
fvm flutter pub get

# 升级依赖
fvm flutter pub upgrade

# 清除依赖缓存
fvm flutter pub cache repair

# 查看过期依赖
fvm flutter pub outdated
```
