## main.dart 概述

`lib/main.dart` 是 OneTJ 应用的入口文件，负责初始化依赖并配置全局设置。

## 完整代码

```dart
import 'package:flutter/material.dart';
import 'package:flutter_localizations/flutter_localizations.dart';
import 'package:onetj/l10n/app_localizations.dart';

import 'package:onetj/app/di/dependencies.dart';
import 'package:onetj/app/app_lifecycle_host.dart';
import 'package:onetj/app/router/app_router.dart';
import 'package:onetj/app/theme/theme_change_notifier.dart';
import 'package:onetj/services/app_update_service.dart';

void main() {
  WidgetsFlutterBinding.ensureInitialized();
  configureDependencies();
  runApp(
    AppLifecycleHost(
      appUpdateService: appLocator<AppUpdateService>(),
      child: const OneTJApp(),
    ),
  );
}

class OneTJApp extends StatelessWidget {
  const OneTJApp({super.key});

  @override
  Widget build(BuildContext context) {
    final ThemeChangeNotifier themeNotifier =
        appLocator<ThemeChangeNotifier>();
    return ListenableBuilder(
      listenable: themeNotifier,
      builder: (BuildContext context, Widget? child) {
        return MaterialApp.router(
          localizationsDelegates: const [
            AppLocalizations.delegate,
            GlobalMaterialLocalizations.delegate,
            GlobalWidgetsLocalizations.delegate,
            GlobalCupertinoLocalizations.delegate,
          ],
          supportedLocales: const [
            Locale('zh', 'CN'),
            Locale('en'),
          ],
          onGenerateTitle: (context) =>
              AppLocalizations.of(context).appTitle,
          theme: ThemeData(
            colorScheme: themeNotifier.lightColorScheme,
            useMaterial3: true,
          ),
          darkTheme: ThemeData(
            colorScheme: themeNotifier.darkColorScheme,
            useMaterial3: true,
          ),
          themeMode: themeNotifier.themeMode,
          routerConfig: AppRouter.router,
        );
      },
    );
  }
}
```

## 初始化流程

### WidgetsFlutterBinding

```dart
void main() {
  WidgetsFlutterBinding.ensureInitialized();
  configureDependencies();
  runApp(...);
}
```

`WidgetsFlutterBinding.ensureInitialized()` 确保 Flutter 框架已完全初始化；随后调用 `configureDependencies()` 完成 get_it 依赖装配。

### AppLifecycleHost

`AppLifecycleHost` 包裹根组件，监听应用生命周期；应用恢复前台时尝试恢复待安装的应用更新。

### runApp

`runApp` 将根组件附加到屏幕。

## 依赖装配

`configureDependencies()` 位于 `lib/app/di/dependencies.dart`，注册所有 Repository、Service 与 ViewModel：

```dart
final GetIt appLocator = GetIt.instance;

void configureDependencies() {
  // Repositories
  appLocator.registerLazySingleton<TokenRepository>(TokenRepository.new);
  appLocator.registerLazySingleton<SettingsRepository>(SettingsRepository.new);
  // ...

  // Services
  appLocator.registerLazySingleton<AuthTokenProvider>(
    () => AuthTokenProvider(repository: appLocator<TokenRepository>()),
  );
  appLocator.registerLazySingleton<TongjiApi>(TongjiApi.new);
  // ...

  // Theme
  appLocator.registerLazySingleton<ThemeChangeNotifier>(
    ThemeChangeNotifier.new,
  );
}
```

## MaterialApp.router 配置

使用 `MaterialApp.router` 配置应用，这是支持 `go_router` 的推荐方式。

### 国际化配置

| 配置项 | 说明 |
|--------|------|
| `localizationsDelegates` | 本地化代理列表（应用自定义 + Material/Widgets/Cupertino） |
| `supportedLocales` | 支持的语言列表（`zh_CN`、`en`） |
| `onGenerateTitle` | 动态生成应用标题 |

### 主题配置

主题由 `ThemeChangeNotifier` 提供亮色 / 暗色 `ColorScheme` 与 `ThemeMode`，外层使用 `ListenableBuilder` 监听主题变化：

```dart
theme: ThemeData(
  colorScheme: themeNotifier.lightColorScheme,
  useMaterial3: true,
),
darkTheme: ThemeData(
  colorScheme: themeNotifier.darkColorScheme,
  useMaterial3: true,
),
themeMode: themeNotifier.themeMode,
```

### 路由配置

```dart
routerConfig: AppRouter.router,
```

## 国际化资源

### ARB 文件位置

```
lib/l10n/
├── app_en.arb           # 英文翻译（模板）
├── app_zh.arb           # 中文翻译
└── app_localizations.dart # 生成的本地化类（勿手动编辑）
```

### l10n.yaml 配置

```yaml
arb-dir: lib/l10n
template-arb-file: app_en.arb
output-localization-file: app_localizations.dart
output-class: AppLocalizations
nullable-getter: false
```

### 使用翻译

```dart
// 在代码中使用
Text(AppLocalizations.of(context).tabDashboard)

// 动态标题
onGenerateTitle: (context) => AppLocalizations.of(context).appTitle,
```

## 路由器配置

### AppRouter 定义

```dart
// lib/app/router/app_router.dart
class AppRouter {
  static final GoRouter router = GoRouter(
    routes: [
      ...launcherRoutes,
      ...loginRoutes,
      ...gradesDetailRoutes,
      ...cetScoreDetailRoutes,
      ...studentExamsDetailRoutes,
      ...physicsLabDetailRoutes,
      ...settingsDetailRoutes,
      homeShellRoute,
    ],
  );
}
```

### 路由路径总览

| 路由 | 路径 | 说明 |
|------|------|------|
| **Launcher** | `/` | 启动页 |
| **Login** | `/login` | 登录页 |
| **Home** | `/home` | 主页容器（重定向到仪表盘） |
| **Dashboard** | `/home/dashboard` | 仪表盘 |
| **Timetable** | `/home/timetable` | 课程表 |
| **Tools** | `/home/tools` | 工具页 |
| **Settings** | `/home/settings` | 设置 |
| **Grades** | `/home/grades` | 成绩 |
| **CET Score** | `/home/cet-score` | 四六级成绩 |
| **Student Exams** | `/home/student-exams` | 考试安排 |
| **Physics Lab** | `/home/tools/physics-lab` | 物理实验 |
| **About** | `/home/settings/about` | 关于 |
| **Time Slots** | `/home/settings/time-slots` | 节次时间 |
| **Developer** | `/home/settings/developer` | 开发者选项 |
| **Logs** | `/home/settings/developer/logs` | 日志查看 |

::: tip 说明

完整路由常量见 `lib/app/constant/route_paths.dart`。主页四个标签页由 `StatefulShellRoute.indexedStack` 承载，其余详情页位于 Shell 外（`context.push` 进入）。

:::

## 主题定制

主题的定制不在 `main.dart` 中硬编码，而是通过设置页修改 `ThemeRepository` 中的偏好，`ThemeChangeNotifier` 会自动重建 `ColorScheme`。详见「Material 主题配置」。

## 调试配置

### 查看日志

应用内置日志查看器（设置 → 开发者选项 → 日志），支持导出日志文件。日志子系统位于 `lib/app/logging/`。
