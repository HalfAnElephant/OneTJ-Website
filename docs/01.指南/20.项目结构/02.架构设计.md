## 分层架构

OneTJ 采用**以 feature 为边界的分层 MVVM** 架构，并在 ViewModel 与 Repository/Service 之间引入 **Application Service** 承担页面用例编排。

### 架构分层

```
┌─────────────────────────────────────────────────────────┐
│                     View (视图层)                        │
│      StatefulWidget/StatelessWidget + AnimatedBuilder    │
└────────────────────┬────────────────────────────────────┘
                     │ 订阅状态 / 转发交互 / 订阅 UiEvent
                     ↓
┌─────────────────────────────────────────────────────────┐
│                  ViewModel (视图模型)                    │
│   BaseViewModel(ChangeNotifier) + Stream<UiEvent>       │
└────────────────────┬────────────────────────────────────┘
                     │ 调用
                     ↓
┌─────────────────────────────────────────────────────────┐
│             Application Service (用例编排层)             │
│   协调 API、Repository、缓存、fallback 等依赖           │
└──────────┬──────────────────────────┬───────────────────┘
           │                          │
           ↓                          ↓
┌────────────────────┐      ┌────────────────────┐
│  Repository (缓存)  │      │  Shared Service    │
│  Hive 本地持久化    │      │  TongjiApi 等 API  │
└────────────────────┘      └────────────────────┘
```

## 各层职责

### View（视图层）

**职责**：渲染 UI，响应用户交互。

**特点**：

- 使用 `StatefulWidget` 或 `StatelessWidget`
- 通过 `AnimatedBuilder` / `ListenableBuilder` 监听 ViewModel 的状态变化
- 通过 `StreamSubscription` 订阅 ViewModel 的 `events`（`Stream<UiEvent>`）处理一次性事件
- 将用户交互委托给 ViewModel

```dart
class _DashboardViewState extends State<DashboardView> {
  late final DashboardViewModel _viewModel;
  StreamSubscription<UiEvent>? _eventSub;

  @override
  void initState() {
    super.initState();
    _viewModel = DashboardViewModel();
    _eventSub = _viewModel.events.listen(_handleEvent);
    _viewModel.load();
  }

  @override
  Widget build(BuildContext context) {
    return AnimatedBuilder(
      animation: _viewModel,
      builder: (context, _) => _buildBody(context),
    );
  }
}
```

### ViewModel（视图模型）

**职责**：展示层状态持有者，连接 View 与 Application Service。

**特点**：

- 继承 `BaseViewModel<TEvent>`（位于 `lib/app/presentation/base_view_model.dart`）
- `BaseViewModel` 本质是 `ChangeNotifier`，通过 `notifyListeners()` 发布状态
- 通过 `emit(event)` 发送 `UiEvent`（导航、SnackBar、Toast、更新提示等）
- 维护 `loading` / `errorMessage` / `errorCode` 等通用状态
- 不直接调用 API，不直接访问缓存 Repository（交由 Application Service）

```dart
class DashboardViewModel extends BaseViewModel<UiEvent> {
  DashboardViewModel({DashboardDataService? dataService})
      : _dataService = dataService ?? DashboardDataService();

  final DashboardDataService _dataService;

  SchoolCalendarData? _calendar;
  bool _calendarLoading = true;

  SchoolCalendarData? get calendar => _calendar;
  bool get calendarLoading => _calendarLoading;

  Future<void> loadSchoolCalendar() async {
    try {
      final data = await _dataService.getSchoolCalendar();
      _calendar = data;
    } catch (error) {
      emit(ShowSnackBarEvent(message: 'Failed to load school calendar'));
    } finally {
      _calendarLoading = false;
      notifyListeners();
    }
  }
}
```

### Application Service（用例编排层）

**职责**：feature 用例和编排层，负责协调 API、Repository、缓存、fallback 及其他依赖。

```dart
class DashboardDataService {
  DashboardDataService({TongjiApi? api}) : _api = api ?? TongjiApi();

  final TongjiApi _api;

  Future<SchoolCalendarData> getSchoolCalendar() async {
    final repo = appLocator<SchoolCalendarRepository>();
    await repo.warmUp();
    return repo.getOrFetch(
      now: DateTime.now(),
      fetcher: _api.fetchSchoolCalendarCurrentTerm,
    );
  }
}
```

### Repository（数据层）

**职责**：仅负责本地/远程数据访问、缓存和持久化，不承担页面工作流。

**特点**：

- 通过 get_it 注册为单例（`appLocator.registerLazySingleton`）
- 基于 `BaseNetCachedRepository` 提供 TTL 缓存、单飞请求合并、`warmUp` / `getOrFetch` / `refresh` / `clearCache`

```dart
class TokenRepository {
  TokenRepository({TokenStorage? storage})
      : _storage = storage ?? HiveTokenStorage();

  final TokenStorage _storage;

  Future<TokenData?> getToken({bool refreshFromStorage = false}) async {
    if (!refreshFromStorage && _cached != null) return _cached;
    _cached = await _storage.read();
    return _cached;
  }
}
```

### Shared Service（共享服务）

**职责**：封装跨 feature 的 API 或基础能力，如 `TongjiApi`、`AuthTokenProvider`。

```dart
class TongjiApi {
  Future<StudentInfoData> fetchStudentInfo() async {
    final uri = Uri.https(_baseUrl, studentInfoPath);
    // 通过 _authorizedGetData 携带 Bearer Token 并解析 ApiResponse
    return _authorizedGetData(uri, parseData: _parseStudentInfo);
  }
}
```

## 依赖注入

OneTJ 使用 **get_it** 完成依赖装配，装配入口位于 `lib/app/di/dependencies.dart`：

```dart
final GetIt appLocator = GetIt.instance;

void configureDependencies() {
  // Repositories —— 单例
  appLocator.registerLazySingleton<TokenRepository>(TokenRepository.new);
  appLocator.registerLazySingleton<StudentInfoRepository>(
    StudentInfoRepository.new,
  );
  // ... 其余 Repository

  // Services —— 单例
  appLocator.registerLazySingleton<AuthTokenProvider>(
    () => AuthTokenProvider(repository: appLocator<TokenRepository>()),
  );
  appLocator.registerLazySingleton<TongjiApi>(TongjiApi.new);
  // ...

  // ViewModels —— 工厂
  appLocator.registerFactory<CetScoreViewModel>(
    () => CetScoreViewModel(dataSource: appLocator<CetScoreDataService>()),
  );
}
```

约定：

- Repository / Service 注册为单例
- ViewModel 注册为工厂，或由 View 直接构造
- 新 Application Service 必须通过构造器注入依赖
- `appLocator` 仅应在 `lib/app/di/` 与必要的 composition root 中使用

## 状态管理

OneTJ 使用 **ChangeNotifier + Stream\<UiEvent\>** 进行状态管理：

1. ViewModel 继承 `BaseViewModel`（`ChangeNotifier`），状态以 getter 暴露，变更后调用 `notifyListeners()`
2. View 使用 `AnimatedBuilder` / `ListenableBuilder` 监听状态变化并重建 UI
3. 一次性事件（`NavigateEvent`、`ShowSnackBarEvent`、`ShowToastEvent`、`AppUpdate*Event`）通过 `Stream<UiEvent>` 发送，View 订阅处理

```dart
// lib/app/presentation/base_view_model.dart
class BaseViewModel<TEvent> extends ChangeNotifier {
  String? errorMessage;
  String? errorCode;
  bool loading = false;

  final StreamController<TEvent> _eventController =
      StreamController<TEvent>.broadcast();

  Stream<TEvent> get events => _eventController.stream;

  @protected
  void emit(TEvent event) {
    if (_isDisposed || _eventController.isClosed) return;
    _eventController.add(event);
  }
}
```

## 路由设计

使用 `go_router` 进行声明式路由管理，路由集中装配于 `lib/app/router/app_router.dart`：

```dart
class AppRouter {
  static final GoRouter router = GoRouter(
    routes: [
      ...launcherRoutes,
      ...loginRoutes,

      // Shell 外的独立详情页面
      ...gradesDetailRoutes,
      ...cetScoreDetailRoutes,
      ...studentExamsDetailRoutes,
      ...physicsLabDetailRoutes,
      ...settingsDetailRoutes,

      // Shell 内的首页、课表、工具与设置一级页面
      homeShellRoute,
    ],
  );
}
```

主页使用 `StatefulShellRoute.indexedStack` 承载四个标签页：

```dart
final StatefulShellRoute homeShellRoute = StatefulShellRoute.indexedStack(
  builder: (context, state, navigationShell) =>
      HomeView(navigationShell: navigationShell),
  branches: [
    StatefulShellBranch(routes: [/* /home, /home/dashboard */]),
    StatefulShellBranch(routes: [/* /home/timetable */]),
    StatefulShellBranch(routes: [...toolsShellRoutes]),
    StatefulShellBranch(routes: [...settingsShellRoutes]),
  ],
);
```

## 架构优势

| 优势 | 说明 |
|------|------|
| **低耦合** | 各层职责清晰，ViewModel 不直接触碰 API 与缓存 |
| **可测试** | Application Service 与 ViewModel 可独立注入 mock 测试 |
| **可维护** | 以 feature 为边界，新增模块不侵入现有代码 |
| **可复用** | Repository 与 Shared Service 可跨 feature 复用 |
