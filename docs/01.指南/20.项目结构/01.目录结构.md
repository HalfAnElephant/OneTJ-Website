## 项目结构概览

OneTJ 采用以 feature 为边界的分层架构组织代码，以下是项目根目录结构：

```
OneTJ/
├── lib/                    # 源代码目录
│   ├── app/               # 应用级配置（常量、DI、异常、日志、路由、主题）
│   ├── features/          # 功能模块（按 feature 划分）
│   ├── models/            # 跨 feature 数据模型与 API 响应
│   ├── repo/              # 数据访问、缓存与持久化
│   ├── services/          # 跨 feature API 与基础服务
│   ├── widgets/           # 共享 UI 组件
│   ├── l10n/              # 国际化资源（ARB + 生成的 AppLocalizations）
│   └── main.dart          # 应用入口
├── assets/                # 静态资源
├── local_packages/        # 本地插件包（flutter_inappwebview fork）
├── scripts/               # 质量检查脚本（flutter_analyze_app）
├── test/                  # 测试代码
├── android/ ios/ ohos/ ...  # 各平台工程目录
├── l10n.yaml              # 国际化生成配置
├── analysis_options.yaml  # 静态分析配置
├── .fvmrc                 # FVM 固定 Flutter 版本
├── pubspec.yaml           # 项目配置
└── CONTRIBUTING.md        # 贡献与协作约定
```

## lib/app/ - 应用级配置

应用级别的常量、依赖注入、异常处理、日志、路由和主题。

```
lib/app/
├── constant/              # 常量定义
│   ├── app_version_constant.dart # 版本信息常量
│   ├── route_paths.dart   # 路由路径常量
│   └── site_constant.dart # API / OAuth 配置常量
├── di/                    # 依赖装配（composition root）
│   └── dependencies.dart  # get_it 注册与 resetDependencies
├── exception/             # 异常处理
│   └── app_exception.dart # 自定义异常体系
├── logging/               # 日志子系统（10 个文件）
│   ├── logger.dart        # AppLogger 门面
│   ├── logging_bootstrap.dart # 日志初始化
│   ├── file_log_sink.dart # 文件日志输出
│   └── ...                # log_entry / log_level / log_formatter 等
├── presentation/          # 共享展示层基础设施
│   ├── base_view_model.dart # BaseViewModel（ChangeNotifier + 事件流）
│   └── ui_event.dart      # UiEvent / NavigateEvent / ShowSnackBarEvent 等
├── router/                # 路由配置
│   └── app_router.dart    # 全局 GoRouter
├── theme/                 # 主题
│   ├── theme_change_notifier.dart   # 主题变更通知器
│   └── theme_color_scheme_builder.dart # ColorScheme 构建器
└── app_lifecycle_host.dart # 应用生命周期监听（恢复待安装更新）
```

## lib/features/ - 功能模块

按照功能划分的模块化代码。每个 feature 通常包含 `application/`、`models/`、`view_models/`、`views/` 与 `routes.dart`。

```
lib/features/
├── launcher/              # 启动模块（初始化与初始路由）
├── login/                 # 登录模块（WebView OAuth）
├── home/                  # 主页 Shell（底部导航容器）
├── dashboard/             # 首页仪表盘
├── timetable/             # 课程表
├── grades/                # 本科生成绩
├── cet_score/             # 四六级成绩
├── student_exams/         # 考试安排
├── tools/                 # 工具页入口
├── physics_lab/           # 物理实验工具
│   ├── features/
│   │   ├── michelson/     # 迈克尔逊干涉仪
│   │   ├── diffraction_grating/ # 光栅衍射
│   │   └── franck_hertz/  # 夫兰克-赫兹实验
│   └── ...
├── settings/              # 设置（主题、布局、节次、开发者、日志等）
├── about/                 # 关于页
└── app_update/            # 应用更新流程
```

### 单 feature 内部结构（以 dashboard 为例）

```
lib/features/dashboard/
├── application/           # 用例编排：API + Repository + 缓存
│   └── dashboard_data_service.dart
├── models/                # feature-local 数据类型
│   ├── dashboard_upcoming_entry_data.dart
│   └── upcoming_entries_calculator.dart
├── view_models/           # UI 状态与 UiEvent
│   └── dashboard_view_model.dart
└── views/                 # Flutter UI
    ├── dashboard_view.dart
    └── widgets/
        └── function_grid.dart
```

## 模块间依赖关系

```
┌─────────────────────────────────────────────┐
│                  Features                    │
│   launcher / login / home / dashboard /      │
│   timetable / grades / cet_score / ...       │
└───────────────────┬─────────────────────────┘
                    │ ViewModel → Application Service
                    ↓
┌─────────────────────────────────────────────┐
│            Services / Repository             │
│   TongjiApi、AuthTokenProvider、Hive 缓存   │
└───────────────────┬─────────────────────────┘
                    ↓
┌─────────────────────────────────────────────┐
│                  Models                      │
│  领域模型、API 响应、值对象                   │
└─────────────────────────────────────────────┘
```

## 文件命名规范

| 类型 | 规范 | 示例 |
|------|------|------|
| **Dart 文件** | 小写下划线分隔 | `login_view_model.dart` |
| **类名** | 大驼峰 | `LoginViewModel` |
| **变量/常量** | 小驼峰 | `tongjiApiBaseUrl`、`oauthScope` |
| **私有类/成员** | 下划线前缀 | `_PrivateClass`、`_privateField` |
| **生成文件** | 原名 + `.g.dart` | `student_info_net_data.g.dart` |
