## 功能概览

OneTJ 致力于为同济大学学生提供一个简洁、高效的信息查询平台。应用以「首页仪表盘 + 课表 + 工具 + 设置」四个主标签组织，并通过 Shell 外的详情页承载成绩、四六级、考试安排与物理实验等深度功能。

## 核心功能

### 首页仪表盘

聚合展示与学生最相关的信息：

- **学期概览**：当前学期名称、当前教学周
- **学籍信息**：学院名称等基本信息
- **即将上课**：按「本周 / 今日 / 未来 N 节」等模式展示接下来要上的课程，并高亮进行中的课程
- **功能宫格**：快捷入口（课表、成绩、四六级、工具、设置等）

### 课程表

- **完整课表**：展示整学期的课程安排
- **详细信息**：课程名称、教室、授课教师、周次
- **时间信息**：星期、节次（开始-结束），支持自定义节次时间
- **智能排序**：自动按星期和节次排序
- **索引系统**：支持按条件快速查找课程

### 成绩查询

- 获取**本科生成绩**（支持按学期查询，`calendarId` 可选）
- 展示课程成绩、学分、绩点等信息

### 四六级成绩（CET）

- 获取并展示 CET 四六级考试成绩

### 考试安排

- 获取学生考试安排
- 当前后端 Scope 尚未为该 client 开通，功能入口暂不可用（详见 API 配置）

### 工具页

- **物理实验**：包含三个实验数据处理工具
  - 迈克尔逊干涉仪（Michelson）
  - 光栅衍射（Diffraction Grating）
  - 夫兰克-赫兹实验（Franck-Hertz）
- 各实验工具支持草稿保存

### 设置与关于

- **主题**：亮色 / 暗色 / 跟随系统，支持自定义主色与辅色
- **主页布局**：可切换功能宫格布局
- **节次时间**：自定义课程表节次时间范围
- **启动壁纸**：自定义启动页壁纸
- **用户数据收集**：按字段授权数据收集
- **开发者选项**：日志查看与导出、调试上传
- **关于页**：贡献者、致谢等

### 应用更新

- 启动与运行期间检查新版本
- 支持跳过版本、下载安装、迁移流程

### 本地缓存

采用 Hive 作为本地数据库：

- **高性能**：Hive 是轻量级、高性能的 NoSQL 数据库
- **离线访问**：缓存数据后可离线查看
- **TTL 缓存**：Repository 基于 `lastFetchedAt` 元数据做 TTL 过期，并支持单飞（single-flight）请求合并
- **自动刷新**：启动时自动获取最新数据

### OAuth2 认证

- **官方认证**：使用同济大学官方 Keycloak 系统
- **安全可靠**：采用标准的 OAuth2 授权码模式（含 `state` 防 CSRF 校验）
- **自动刷新**：Access Token 过期时自动使用 Refresh Token 刷新

### 国际化

- 支持中文、英文切换
- 使用 ARB 格式管理翻译资源（`lib/l10n/app_*.arb`）
- 通过 `AppLocalizations` 在代码中访问翻译

## 架构特性

### 分层 MVVM 架构

```
┌─────────────────────┐
│        View         │  Flutter UI 组件
└──────────┬──────────┘
           │ 订阅状态 / 转发交互
           ↓
┌─────────────────────┐
│      ViewModel      │  BaseViewModel(ChangeNotifier) + UiEvent
└──────────┬──────────┘
           │ 调用
           ↓
┌─────────────────────┐
│  Application Service │  用例编排（API + Repository + 缓存）
└──────────┬──────────┘
           ↓
┌─────────────────────┐
│  Repository / Service │  数据访问与共享服务
└─────────────────────┘
```

### 依赖注入

通过 **get_it** 完成依赖装配（`lib/app/di/dependencies.dart`），Repository 注册为单例，ViewModel 注册为工厂或由 View 直接构造。

主要 Repository 包括：

- **TokenRepository**：管理访问令牌
- **StudentInfoRepository**：管理学生信息缓存
- **SchoolCalendarRepository**：管理校历缓存
- **CourseScheduleRepository**：管理课程表缓存
- **UndergraduateScoreRepository**：管理本科生成绩缓存
- **CetScoreRepository**：管理四六级成绩缓存
- **StudentExamRepository**：管理考试安排缓存
- **SettingsRepository / ThemeRepository**：管理设置与主题偏好

### 状态管理

- ViewModel 继承 `BaseViewModel<TEvent>`（本质是 `ChangeNotifier`），通过 `notifyListeners()` 发布状态
- 一次性 UI 事件（导航、Toast、SnackBar、更新提示）通过 `Stream<UiEvent>` 发送
- View 通过 `AnimatedBuilder` / `ListenableBuilder` 监听 ViewModel，通过 Stream 订阅处理 `UiEvent`

### 路由管理

使用 go_router 进行声明式路由：

- `StatefulShellRoute.indexedStack` 承载主页四个标签页
- 类型安全的路由导航
- Shell 外详情页（成绩、四六级、考试、物理实验、设置二级页）
- 自定义过渡动画
